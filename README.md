This simple program generates random full names by combining individual elements (first names and surnames).

Requirements:
- Python 3.13 (tested, but it should be compatible with older versions of Python 3)

To run the program, use:

```
python index.py
```

Add a list of names to each file (names.txt and surnames.txt). The program will randomly select a name and a surname from these files and combine them to generate a full name.
